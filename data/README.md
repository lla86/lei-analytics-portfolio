# Synthetic data dictionary

Every CSV in `synthetic/` is generated by `python3 scripts/generate_demo.py`, seed `20261112`. Synthetic IDs have no link to people or businesses. No original project datasets are copied. Dates are illustrative and fixed, not current operations.

| File | Grain / key | Fields and units |
| --- | --- | --- |
| deliveries.csv | One order / order_id | service_date: ISO date, September 2025; zone: fictional Central/North/South; status: delivered/cancelled; promised_minutes: 50; actual_minutes: elapsed minutes for delivered orders, empty for cancellations; x_km/y_km: fictional coordinates, not geocoded addresses |
| players.csv | One player / player_id | signup_date: September 1-27; variant: randomized A/B, expected 50:50 |
| sessions.csv | One player and exact relative day / player_id + day_number | day_number in 0,1,3,7,14. A row means at least one session that day; absence means no activity in this fully observed simulator |
| customers.csv | One customer / customer_id | Snapshot before September campaign; recency_days: days since last purchase; purchases_180d: transaction count in prior 180 days; spend_cad: total historical spend in that same window; segment: rules below |
| campaigns.csv | One recipient / customer_id | One September demo campaign per customer; responded: 1 if response within a fictional 14-day window, 0 otherwise; all recipients have complete follow-up |

## Definitions

- Delivery on-time rate = delivered orders with actual_minutes <= promised_minutes / delivered orders. Cancellations are excluded from the denominator and reported separately. September 1-30 inclusive; no real service timezone is implied.
- Cancellation rate = cancelled orders / all orders. Mean duration uses delivered orders only. Ratios are recalculated from counts, never averaged across zones.
- D1 / D7 retention = distinct eligible players with activity exactly 1 / 7 calendar days after signup / distinct eligible players. Both use the same fully D7-mature population (`signup_date + 7 days <= 2025-09-30`). This is exact-day, not rolling retention. Newer cohorts are excluded, not assigned zero.
- A/B primary endpoint is exact-day D7 retention; two-sided alpha 0.05. Difference is B minus A, in percentage points. 95% Wald interval uses unpooled variance; z test uses pooled null variance. SRM uses a 50:50 chi-square test with one degree of freedom. No repeated peeking, multiple-primary testing, or real-world causal claim is supported.
- Segment precedence: Loyal if recency <= 60 and purchases >= 8; otherwise At risk if recency > 90; otherwise Developing. Spend is profiled, not an independent input to this deliberately simple segmentation rule. All features precede the campaign.
- Campaign response rate = responded / assigned recipients in segment. A response is an illustrative campaign action, not necessarily a sale. Historical spend is not attributed campaign revenue. This observational comparison cannot establish incremental lift or ROI.

The simulator intentionally encodes different response probabilities by segment and a small D7 variant difference. Patterns are assumptions of a teaching example, not discovered customer or player behavior. The manifest records SHA-256 hashes for all generated CSV inputs.
